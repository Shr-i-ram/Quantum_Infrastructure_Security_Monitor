# QISM Dataset Schema & Feature Dictionary

## 1. Overview

The Quantum Infrastructure Security Monitor (QISM) generates research-grade telemetry structured into 130 total columns per telemetry window record.
Every telemetry record is derived from authentic Monte Carlo physical events generated by the QISM simulator engine.

### Feature Categorization
- **Observable Features (76 features)**: Directly measurable or physically derivable by a real-time monitor deployed at Bob's station. **Permitted as inputs to ML/QML models.**
- **Ground-Truth Labels & Simulator Internals (18 columns)**: Latent simulator state, attack injection indicators, and theoretical bounds. **STRICTLY PROHIBITED as model inputs.**
- **Identifier & Window Metadata (5 columns)**: Sequence indices and temporal boundaries.
- **Raw Event Counters & Histograms (31 columns)**: Intermediate event sums and fine-grained distributions, excluded from standard ML feature vectors to prevent dimensionality explosion.

## 2. Observable Features (76 Columns — Model Inputs Allowed)

These 76 features constitute the canonical input representation for classical and quantum anomaly detectors.

### 2.1 QBER & Error Observables (6)
| Feature Name | Type | Unit | Range | Physical Meaning |
|---|---|---|---|---|
| `qber` | float64 | dimensionless | [0.0, 1.0] | Total sifted quantum bit error rate across all matched bases ($N_{\text{err}} / N_{\text{sift}}$). |
| `qber_z` | float64 | dimensionless | [0.0, 1.0] | Sifted error rate in the computational ($Z$) basis. |
| `qber_x` | float64 | dimensionless | [0.0, 1.0] | Sifted error rate in the diagonal ($X$) basis. |
| `sifted_count` | int64 | pulses | $\ge 0$ | Total pulses where Alice and Bob bases matched and a single click was registered. |
| `sifted_rate` | float64 | dimensionless | [0.0, 1.0] | Sifted key fraction: `sifted_count / n_pulses`. |
| `error_count` | int64 | pulses | $\ge 0$ | Discrepant bit count between Alice emitted bit and Bob measured bit. |

### 2.2 Decoy-State Gains & Residuals (6)
| Feature Name | Type | Unit | Range | Physical Meaning |
|---|---|---|---|---|
| `signal_gain` | float64 | dimensionless | [0.0, 1.0] | Overall detection gain $Q_\mu$ for signal state pulses ($\mu \approx 0.50$). |
| `decoy_gain` | float64 | dimensionless | [0.0, 1.0] | Overall detection gain $Q_\nu$ for decoy state pulses ($\nu \approx 0.10$). |
| `vacuum_gain` | float64 | dimensionless | [0.0, 1.0] | Detection gain $Q_{\text{vac}}$ during vacuum state emissions ($\nu_0 = 0$). |
| `signal_decoy_residual` | float64 | dimensionless | [-1.0, 1.0] | $R_\mu = Q_{\text{obs},\mu} - Q_{\text{pred},\mu}$. Sensitive to PNS multi-photon manipulation. |
| `decoy_decoy_residual` | float64 | dimensionless | [-1.0, 1.0] | $R_\nu = Q_{\text{obs},\nu} - Q_{\text{pred},\nu}$. Decoy model residual. |
| `vacuum_residual` | float64 | dimensionless | [-1.0, 1.0] | Residual between vacuum detections and baseline dark count expectation. |

| `dark_click_fraction` | float64 | dimensionless | [0.0, 1.0] | Fraction of total registered clicks attributed to dark noise and background stray light. |

## 3. Ground-Truth & Labels (18 Columns — PROHIBITED as ML Inputs)

These fields are strictly evaluation targets and latent simulation states. They must be removed from any feature matrix prior to model ingestion:

| Column Name | Type | Allowed Values | Interpretation |
|---|---|---|---|
| `ground_truth_attack_active` | int64 | `{0, 1}` | **Primary target label**: 1 if attack is active, 0 if normal. |
| `ground_truth_attack_type` | string | `{intercept_resend, channel_loss, source_manipulation, detector_manipulation, timing, pns, None}` | Attack mechanism family name. |
| `ground_truth_attack_phase` | string | `{none, onset, active, recovery}` | Temporal attack lifecycle state. |
| `ground_truth_attack_fraction`| float64 | [0.0, 1.0] | Fraction of window pulses under active attack perturbation. |
| `ground_truth_mean_severity` | float64 | [0.0, 1.0] | Continuous normalized attack perturbation severity $\xi$. |
| `ground_truth_attack_id` | string | e.g. `atk_split_0001` | Unique attack episode instance identifier. |
| `afterpulse_rate_ground_truth`| float64 | [0.0, 1.0] | Simulator internal carrier trap probability. |
| `mean_afterpulse_delay` | float64 | s | Simulator internal trap release lifetime. |
| `yield_0` to `yield_10` (11 cols) | float64 | [0.0, 1.0] | Theoretical channel photon yields $Y_n$ for $n = 0, \dots, 10$. |

---

## 4. Identifiers & Metadata (5 Columns)
- `run_id`: Execution run identifier (`run_0000`).
- `scenario_id`: Frozen experimental condition identifier (`split_0000`).
- `window_id`: Sequential 0-indexed window counter within run.
- `window_start_pulse`: Starting pulse index of window.
- `window_end_pulse`: Ending pulse index of window.

## 5. Raw Event Counters & State Bins (31 Columns)
- Histograms: `timing_histogram_counts`, `timing_histogram_edges`, `detector_0_interarrival_histogram_counts`, `detector_0_interarrival_histogram_edges`, `detector_1_interarrival_histogram_counts`, `detector_1_interarrival_histogram_edges`.
- Event counters: `n_pulses`, `n_signal`, `n_decoy`, `n_vacuum`, `n_sifted_z`, `n_sifted_x`, `n_errors_z`, `n_errors_x`, `n_double`, `n_detection`, `n_dark_0`, `n_dark_1`, `n_candidate_0`, `n_candidate_1`, `n_dead_rejected_0`, `n_dead_rejected_1`, `n_afterpulse_detected`, `n_primary_avalanches`.
- State distributions: `mean_photon_number`, `photon_variance`, `vacuum_fraction`, `single_photon_fraction`, `multiphoton_fraction`, `mean_channel_transmittance`.
